# 米斯卡托尼克讲义

通过九章视觉小说介绍克苏鲁神话。全幅场景、底部对白、55 条档案与四种结语；支持手机横竖屏和浏览器本地存档。

## 在线阅读

[打开米斯卡托尼克讲义](https://kurisu0306.github.io/cthulhu-mythos-vn/index.html)

手机可直接打开此链接。进度保存在当前设备、当前浏览器中，不会在手机与电脑之间自动同步。

## 本地查看

直接打开 `index.html`，或在本目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。网页无需安装运行依赖；Google Fonts 异步加载；加载失败或一直无响应时先使用系统字体，不阻塞正文与阅读交互。

## 阅读机制

- 点击对白匣或继续按钮推进；打字时第一次点击补完当前文字。空格、Enter、右箭头和下箭头也可推进；按钮保留自身的键盘操作。
- `C` 打开档案，Escape 关闭抽屉。目录只允许跳回已经访问的章节，重读已结算对白不会再次扣理智。
- 序章选择消耗 2 或 7 点理智，第五章选择消耗 12 或 2 点。正常完整阅读的四种组合分别剩余 26、36、21、31 点，各有一段不同的结语。
- 档案解锁是阅读奖励；主动索要可提前解锁，完整阅读任一路线都能解锁全部 55 条。
- 每次推进都会保存对白位置、理智、解锁、已读章节和已结算效果；在选项页刷新可返回原选项。读完后保留结语与档案，明确选择“从头再读”才重置。
- 旧版存档沿用原来的键迁移；旧格式未记录逐行结算信息，因此已读位置按已结算处理，保留原理智，避免重复扣分。无法追溯修正旧版已经多扣的理智。

## 内容与结构

`index.html` 包含页面、样式、程序化画布、`CODEX` 档案、`CH` 章节和阅读引擎。`SOURCES.md` 记录考据修正及来源；档案内也提供对应底本链接。

出处标签区分洛氏原著、同时代共创、德雷斯体系、后世分类、后人扩展与流行文化。作品年份注明首刊或创作年；文学解读与后世规则分开，不预设统一的“官方神谱”。

手机设置了 viewport 与安全区；长对白、开场和抽屉可滚动。明暗主题跟随系统，“减少动态效果”关闭打字与持续画布动画，切换场景、主题或尺寸仍会重绘。

## 验证

网页本身无需构建。浏览器回归测试使用 Node.js、Playwright 和 Chrome：

```bash
npm install
python3 -m http.server 8768 --bind 127.0.0.1
# 在另一个终端
npm test
```

测试覆盖四条完整路线、全部档案、每种结语、新旧存档、选项刷新、损坏存档、章节重读、快速按键、抽屉焦点、终章档案、手机横竖屏、字体离线和减少动画设置。截图输出到被忽略的 `test-results/`。

可通过 `TEST_BASE_URL` 验证已部署页面；通过 `TEST_BROWSER=webkit` 或 `firefox` 选择已安装的其他 Playwright 浏览器；线上验证需要代理时，可设置 `TEST_PROXY`。测试结果需区分模拟手机视口与真实手机设备。

## 发布与维护

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 禁用额外页面转换。验证通过后提交并推送更新，等待 Pages 部署成功，再检查线上网页。

修改考据记录后，运行 `python3 scripts/build-sources.py` 更新手机可读的 `sources.html`。
